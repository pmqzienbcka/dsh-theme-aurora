# Aurora 主题

给 DSH Web 客户端用的外观插件：背景图片、毛玻璃、压暗、字体、圆角，以及可以自由摆放的图片层。

## 功能

- **背景图片**：会话页与侧边栏可分别设置，支持填充 / 适应 / 拉伸 / 平铺 / 居中五种缩放；未设置侧边栏图片时，一张图连续铺满整个窗口（含标题栏），可整体压暗 0–100%（100% 为纯黑）。
- **模糊度**：背景图可单独加模糊（0–40px），不影响文字。
- **毛玻璃**：侧边栏与会话顶栏各自独立开关、独立模糊度。
- **字体**：正文/代码字体选择（Host 侧读取本机已装字体）、字号、文字颜色。
- **圆角**：整体缩放界面圆角（40%–200%）。
- **图片层**：添加任意张图片，在页面上直接拖动、拖右下角缩放、点 × 删除；只在窗口最大化时显示，绘制在背景之上、会话内容之下。

## 使用

安装后在 **设置 → 主题外观** 中调整，改动点「应用」生效。图片层添加后会自动进入布局模式，点底部的「应用布局」保存并退出。

## 存储与隐私

- 配置存在浏览器 `localStorage`，图片以原始字节存在 `IndexedDB`（不上传、不重编码，仅在绘制时生成屏幕尺寸副本）。
- 插件的 Host 半边只提供了一个本地路由 `GET /aurora/fonts`，用于把本机字体列表交给设置页；它不接受外部请求、不写入文件、不联网。

## 已知限制

- 字体枚举依赖 Windows 字体目录，非 Windows 环境会回退到内置常用字体列表。
- 「图片层」只在窗口最大化（或全屏）时显示；窗口缩小时隐藏但配置保留。
- 图片模糊是预烘焙的：修改模糊度并点应用会重新生成一次显示副本。

## 开发

仓库根目录：

- `index.js` / `lib/fonts.mjs`：Host 半边（字体枚举与路由）。
- `client.js`：Client 半边（设置页与运行时样式）。
- `scripts/asar.mjs`、`scripts/probe.mjs`：排查已打包客户端用的临时工具，不随插件发布。
